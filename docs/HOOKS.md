# Hooks and regions

Generated by `php flatbb hooks:list` on 2026-09-05. Do not edit by hand.

Filters receive `($value, array $ctx)` and return the new value (or null to keep it). Events receive `(null, array $ctx)`.
Regions are filters named `region.<position>` whose value is HTML (or an array for list regions). Inline regions run inside loops: **no database queries** in their callbacks.
